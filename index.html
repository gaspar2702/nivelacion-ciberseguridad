3. Acceso Remoto (SSH)

Usa la terminal de tu PC para conectarte al servidor de OverTheWire.

Instrucciones de Conexión:

  1. Abre el CMD (Windows) o Terminal (Mac/Linux).
  2. Escribe: ssh bandit0@bandit.labs.overthewire.org -p 2220
  3. Cuando pida password, escribe: bandit0 (No se verá mientras escribes).
  4. Escribe ls y luego cat readme para hallar la clave.
